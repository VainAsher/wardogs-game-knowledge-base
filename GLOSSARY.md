# Glossary

| Term | Definition | Source |
|------|------------|--------|
| WARDOGS | 100-player, 3-team tactical FPS by Bulkhead, published by Team17 | steam-store |
| Early Access | Steam pre-release state; WARDOGS entered it 10 Sept 2026 | team17-press |
| Control Zone | Randomised 2x2 km objective area per match; team with most players inside scores, first to 100 wins | steam-store |
| Hot Zone | Smaller area where presence and cash count double (player-reported) | allthings-hotzone |
| Role track | Per-role XP track gating unlocks; count and names differ by source (player-reported) | allthings-roles |
| Season | Period after which cash and XP reset; cash-to-Gold-Bar conversion rests on a single commercial source and is unverified | timesaver-s2 |
| Loadout | Weapons, gear, utility and vehicles bought with cash at the vendor for one life | steam-store |
| WARDOG Level | Account-wide level unlocking general items (player-reported) | keengamer-progression |
| Re-buy Loadout | Vendor option rebuilding the previous kit after death (player-reported) | keengamer-progression |
| Cash | In-game currency earned by teamplay and spent on per-life loadouts; persists between matches; not purchasable | steam-store |
| Account balance | Persistent cash total that match outcomes feed into | team17-press |
| Gold Bars | Second currency named in the Team17 press release as not purchasable; seasonal role unverified | team17-press |
| FOB (Forward Operating Base) | Player-deployed kit creating a build zone and supply storage; not a respawn point; $7,500 as of Season 1 (player-reported) | gfinity-s1 |
| Hammer (Small/Medium/Large) | Build tool in three tiers gating which structures can be started (player-reported) | keengamer-fob |
| Pallet | Container for hauling supplies to a FOB | bisect-012 |
| Vehicle Vendor | Safe-zone stall selling vehicles in LAND and AIR tabs; higher tiers need an unlock fee plus a level (player-reported) | allthings-vehicles |
| Supply types | Build, Ammo, Fuel and Mechanical supplies feeding different FOB structures (player-reported) | keengamer-fob |
| Variation (map) | Bulkhead's undefined term for the three versions of each launch map; meaning unverified | team17-press |
| Bakurani / Ozeti / Zestafona | Community-listed map names (player-reported); Bakurani smallest, others about 4x | allthings-maps |
| Community server | Host-rented server in the Community browser, split from Official in patch 0.11 | playday-011 |
| RCON (WARDOGS) | Remote admin interface; reported by unofficial sources as HTTP API on port 7776, off by default | wardogs-tech-rcon |
| AllowedHosts | RCON setting added in 0.1.2 restricting hosts that may reach RCON | ingamenews-012 |
| WD-L020 | Crash code tied to Windows 11 update KB5124010, fixed in 0.1.2 | ingamenews-012 |
| Supporter Edition | Base game plus cosmetic-only Supporter Pack (GBP 45.99 on Steam, 2026-10-08) | steam-store |
| Closed Beta | Pre-launch playtest gated by pre-order or a Steam page request | gameluster-wishlists |
| Approved host | Hosting provider the studio permits to run community servers; fan-relayed names: QONZER, BisectHosting, xREALM | neonsect-servers-guide |
| Deploy screen | In-game flow to the Official and Community server browsers; 0.1.2 added Infantry Mode and Low-Level options | mp1st-012 |
| Config document | Whole ServerSettings.ini text read and replaced via /v1/config, with If-Match revision checks (unofficial) | server-refs |
| CL-501228 | Build (2026-09-14) reported to have removed eight RCON write endpoints (unofficial) | server-refs |
| KB5124010 | Windows 11 update reported by press as the trigger of WD-L020 crashes | mp1st-012 |
| Kernel-level anti-cheat | Driver-level anti-cheat; the Steam page states WARDOGS uses it, product unnamed | steam-store |
| Supporter Pack | Cosmetic DLC: 3 Starter Weapon camos, 3 branded camos, scoreboard icon, 2 bobbleheads | steam-api |
| Season 1.0 | Label of the launch-day changelog covering unlock levels, XP curve and prices | gfinity-s1 |
| Play area (community) | Community term for a named circle (reported 500 m radius) conflicting with the official 2x2 km Control Zone | allthings-maps |
| Drill tower | Capturable map tower revealing part of a key code (community-reported) | allthings-zestafona |
| Gold Market | Official name for the cosmetic store bought with Gold Bars (18 Feb 2026 FAQ); relation to the roadmap's "Black Market & Vault" unresolved | steam-news 1825093633182385 |
| Role track (official) | Official Season 1 changelog names six: Career, Medic, Recon, Support, Driver, Pilot; "Assault" is a player-guide name | steam-news 1843481262690549 |
| XP band | A level at which the Season 1 changelog publishes an XP requirement (levels 6 to 50) | steam-news 1843481262690549 |
| Schematic | Placed, unbuilt structure; destroying one pays a reduced reward since 0.1.2 | steam-news 1845383656376490 |
| Economy abuse | Cash or XP exploits, XP farming or real money trading; punished by timed bans and a reset, or permanent bans | steam-news 1843481262698449 |
| CIWS | Close-in weapon system anti-air buildable; 2 Oct 2026 hotfix cut time to destroy a Havoc from about 12 s to about 6 s (official) | steam-news 1845383656386801 |
| IR Rangefinder | Item disabled in the vendor by the 2 Oct 2026 hotfix until Season 02, when it requires batteries; the post title says IR Goggles | steam-news 1845383656386801 |
| WAR DYNAMICS FRAMEWORK | Bulkhead's custom Unreal Engine 5 enhancements for 100-player combat | steam-news 1825093633182385 |
| Reliability grade (R1-R4) | KB judgement of a source against official text: R1 reliable to R4 do not cite alone | community-and-source-reliability |
| Baseline value | A number stamped with the game version it was true for, so later seasons can be diffed mechanically | - |
