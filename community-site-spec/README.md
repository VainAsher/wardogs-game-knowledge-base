# Wardogs Community Hub — website specification

This folder holds the developer handoff for the Wardogs UK community website. It is **not** part of the Knowledge Base content: it sits outside `docs/`, so it is not published to the MkDocs wiki and is not checked by `validate.py`, `check_links.py`, or the root-level markdownlint job.

| Path | Contents |
|---|---|
| `wardogs-community-spec/` | Current spec pack, Revision 1.1 (start with its `README.md`) |
| `Wardogs_Community_Website_Developer_Handoff_v1.1.zip` | Same pack, zipped for sharing |
| `original/` | Unmodified Revision 1.0 draft, kept for comparison |
| `FIX_PLAN.md` | Review findings and the planned fixes |
| `FINAL_REVIEW.md` | Fix log, further issues found, and decisions still open |
| `changes.diff` | Line-by-line diff from 1.0 to 1.1 |

The spec's wiki integration (`wardogs-community-spec/08_GAME_WIKI_INTEGRATION.md`) proposes two changes to this repository: a base-URL input to `scripts/build_site.py`, and a MkDocs Material theme override. Neither change has been made; they need a KB maintainer's review.
